3. Technology Stack: What, Why & Architectural Value

Every technology integrated into AI Smartgate Estate OS was evaluated and selected against strict enterprise criteria: latency, security, developer velocity, and horizontal scalability.

1. Frontend Presentation: React 19 & Vite 7 Client Layer
Modern Single Page Application (SPA) with optimistic UI updates and instant HMR development compilation.
  • Why it was chosen: React 19 provides superior concurrent rendering and sub-millisecond DOM transitions. Vite eliminates webpack bundling overhead, compiling TypeScript assets in under 6 seconds.
  • Architectural role: Delivers instant role-tailored viewports (Super Admin, Society Admin, Resident, Gate Guard) without full-page reloads, retaining offline cached state during network drops.
2. Application Engine: Node.js Express 5 API Gateway Layer
Non-blocking, event-driven HTTP server hosting all RESTful APIs, cookie validation, and metrics endpoints.
  • Why it was chosen: Express 5 features native Promise rejection handling, high throughput, and lightweight footprint. Node.js shared TypeScript types with the frontend for zero schema drift.
  • Architectural role: Manages authentication middleware, body validation, static upload serving, and Prometheus telemetry collection.
3. Relational Persistence: PostgreSQL 17 Database Layer
Enterprise-grade ACID relational database operating with transactional guarantees on port 5432.
  • Why it was chosen: Real estate and security management requires strict relational consistency (e.g., visitors must bind to units, units bind to societies). PostgreSQL 17 provides advanced query optimization and index concurrency.
  • Architectural role: Stores 19 normalized domain models including users, units, visitor records, parcel deliveries, purchase logs, and maintenance subscriptions.
4. Object-Relational Mapping: Prisma ORM 6.4 Data Access Layer
Type-safe schema definition language, auto-generated TypeScript query client, and zero-drift migration engine.
  • Why it was chosen: Eliminates SQL injection vulnerabilities by default with parameterized queries. Guarantees 100% type safety between database tables and API return signatures.
  • Architectural role: Manages connection pooling (tuned to connection_limit=25) and multi-table queries via prisma.$transaction to avoid connection pool exhaustion.
5. Cryptographic Security: Argon2id Hashing & HttpOnly JWT Security Layer
Password hashing utilizing the winner of the Password Hashing Competition (PHC) alongside stateless tamper-proof sessions.
  • Why it was chosen: Unlike legacy bcrypt or SHA256, @node-rs/argon2 is memory-hard, making GPU-accelerated and ASIC rainbow table brute-force attacks computationally unfeasible.
  • Architectural role: Tokens are stored exclusively in HttpOnly, SameSite=Lax browser cookies, mitigating 100% of Cross-Site Scripting (XSS) credential theft.
6. Real-Time Comms: Socket.io Engine Real-Time Layer
Bidirectional WebSocket communication layer with room-based broadcast routing and automatic transport fallback.
  • Why it was chosen: Gate security cannot rely on HTTP polling (which introduces seconds of lag and exhausts server bandwidth). Socket.io delivers gate events to resident screens in under 40 milliseconds.
  • Architectural role: Segregates traffic into secure isolated rooms (society:{id}, unit:{id}, gates:{id}) so gate requests reach only the corresponding flat owner.
7. Payments & Telephony: Razorpay & Twilio / Nodemailer Integration Layer
Server-side payment order generation, cryptographic signature validation, and multi-channel OTP delivery.
  • Why it was chosen: Razorpay provides compliant Indian payment rails (UPI, Cards, NetBanking). Twilio and Gmail SMTP provide resilient OTP fallback mechanisms.
  • Architectural role: Validates webhook authenticity using HMAC-SHA256 signatures before activating society subscriptions.

6. Security Hardening & Zero-Trust Matrix

🛡️ Authentication & Session
  • Argon2id password hashing prevents rainbow tables and ASIC attacks.
  • Tokens stored in HttpOnly, SameSite=Lax cookies prevent XSS theft.
  • Stateless JWT signing with HS256 secret keys.
🔒 Data Isolation & Multi-Tenancy
  • Strict tenant scoping via societyId on all queries.
  • Prisma parameterized queries protect against 100% of SQL injection.
  • Input validation on registration, OTP, and payments.
